一张 `documents` 表（存文件名、上传时间、文件路径等）；一张 `chat_history` 表（持久化保存聊天记录，方便以后查看）。

1. 文档元数据表：`documents`
2. 对话历史表：`chat_history`
3. 会话管理表：`chat_sessions`

### 1. 文档元数据表：`documents`

这张表主要用于 Agentic RAG 中的 `query_metadata` 工具，帮助大模型通过结构化数据（如时间、标签、标题）进行精准过滤，避免不必要的全文检索。

#### 📊 表结构总览

| **字段名 (Field)** | **数据类型 (Type)** | **约束与索引 (Constraints/Indexes)** | **描述说明 (Description)**                |
| ------------------ | ------------------- | ------------------------------------ | ----------------------------------------- |
| **id**             | uint / int          | 主键 (Primary Key), 自增             | 记录唯一标识                              |
| **file_name**      | varchar(255)        | 非空 (Not Null)                      | 原始 Markdown 文件名                      |
| **title**          | varchar(255)        | 普通索引 (Index)                     | 文档标题（用于大模型按标题检索）          |
| **file_path**      | varchar(512)        | 非空 (Not Null)                      | 文件在本地的存储路径或 OSS 地址           |
| **tags**           | varchar(255)        | 普通索引 (Index)                     | 文档标签（逗号分隔或 JSON，方便按类检索） |
| **word_count**     | int                 | 默认为 Null                          | 文档字数统计                              |
| **summary**        | text                | 默认为 Null                          | 文档的 AI 简短摘要（可选扩展）            |
| **created_at**     | datetime            | 普通索引 (Index)                     | 上传/创建时间（用于大模型按时间筛选）     |
| **updated_at**     | datetime            | 默认为 Null                          | 记录更新时间                              |
| **deleted_at**     | datetime            | 普通索引 (Index)                     | GORM 软删除标记时间                       |

#### 💻 Go (GORM) 模型代码



```
package models

import (
	"time"
	"gorm.io/gorm"
)

// Document 对应 documents 表，存储 Markdown 文件元数据
type Document struct {
	ID        uint           `gorm:"primarykey"`
	FileName  string         `gorm:"type:varchar(255);not null;comment:'原始文件名'"`
	Title     string         `gorm:"type:varchar(255);index;comment:'文档标题(从YAML提取或同文件名)'"`
	FilePath  string         `gorm:"type:varchar(512);not null;comment:'本地存储路径或OSS地址'"`
	Tags      string         `gorm:"type:varchar(255);index;comment:'文档标签，逗号分隔或JSON格式，方便检索'"`
	WordCount int            `gorm:"type:int;comment:'字数统计'"`
	Summary   string         `gorm:"type:text;comment:'文档生成时的AI简短摘要(可选)'"`
	CreatedAt time.Time      `gorm:"index;comment:'上传/创建时间'"`
	UpdatedAt time.Time
	DeletedAt gorm.DeletedAt `gorm:"index"`
}
```

#### 💾 MySQL DDL 建表语句



```
CREATE TABLE `documents` (
  `id` int unsigned NOT NULL AUTO_INCREMENT,
  `file_name` varchar(255) NOT NULL COMMENT '原始文件名',
  `title` varchar(255) DEFAULT NULL COMMENT '文档标题(从YAML提取或同文件名)',
  `file_path` varchar(512) NOT NULL COMMENT '本地存储路径或OSS地址',
  `tags` varchar(255) DEFAULT NULL COMMENT '文档标签，逗号分隔或JSON格式，方便检索',
  `word_count` int DEFAULT NULL COMMENT '字数统计',
  `summary` text COMMENT '文档生成时的AI简短摘要(可选)',
  `created_at` datetime(3) DEFAULT NULL COMMENT '上传/创建时间',
  `updated_at` datetime(3) DEFAULT NULL,
  `deleted_at` datetime(3) DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `idx_documents_title` (`title`),
  KEY `idx_documents_tags` (`tags`),
  KEY `idx_documents_created_at` (`created_at`),
  KEY `idx_documents_deleted_at` (`deleted_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='文档元数据表';
```

### 2. 对话历史表：`chat_history`

这张表用于持久化保存 Agent 和用户的交互记录。由于大模型在 Agentic 模式下会产生“调用工具”的中间思考过程，这张表设计了 `role` 和 `tool_name` 来清晰记录 Agent 的每一次决策。

#### 📊 表结构总览

| **字段名 (Field)** | **数据类型 (Type)** | **约束与索引 (Constraints/Indexes)** | **描述说明 (Description)**                      |
| ------------------ | ------------------- | ------------------------------------ | ----------------------------------------------- |
| **id**             | uint / int          | 主键 (Primary Key), 自增             | 记录唯一标识                                    |
| **session_id**     | varchar(64)         | 非空, 普通索引 (Index)               | 会话 ID，用于串联多轮对话上下文                 |
| **role**           | varchar(20)         | 非空 (Not Null)                      | 角色区分：`user`, `assistant`, `system`, `tool` |
| **content**        | text                | 非空 (Not Null)                      | 对话的具体文本内容，或工具返回的执行结果        |
| **tool_name**      | varchar(64)         | 默认为 Null                          | 如果 `role` 为 `tool`，则记录调用的工具名称     |
| **created_at**     | datetime            | 普通索引 (Index)                     | 消息产生的时间                                  |
| **updated_at**     | datetime            | 默认为 Null                          | 记录更新时间                                    |
| **deleted_at**     | datetime            | 普通索引 (Index)                     | GORM 软删除标记时间                             |

#### 💻 Go (GORM) 模型代码

```
package models

import (
	"time"
	"gorm.io/gorm"
)

// ChatHistory 对应 chat_history 表，持久化存储 Agent 对话记录
type ChatHistory struct {
	ID        uint           `gorm:"primarykey"`
	SessionID string         `gorm:"type:varchar(64);not null;index;comment:'会话ID，用于串联多轮对话'"`
	Role      string         `gorm:"type:varchar(20);not null;comment:'角色: user, assistant, system, tool'"`
	Content   string         `gorm:"type:text;not null;comment:'对话内容或工具返回结果'"`
	ToolName  string         `gorm:"type:varchar(64);comment:'如果是tool调用，记录调用的工具名称(可选)'"`
	CreatedAt time.Time      `gorm:"index;comment:'消息发生时间'"`
	UpdatedAt time.Time
	DeletedAt gorm.DeletedAt `gorm:"index"`
}
```

#### 💾 MySQL DDL 建表语句

### 3. 会话管理表：`chat_sessions`

这张表专门用来管理每一次“新建对话”的宏观信息。当用户点击“新建对话”时，先在这里生成一条记录；之后在这个对话框里发的所有消息，都带上这个记录的 ID 存入 `chat_history`。

#### 📊 表结构总览

| **字段名 (Field)** | **数据类型 (Type)** | **约束与索引 (Constraints/Indexes)** | **描述说明 (Description)**                                   |
| ------------------ | ------------------- | ------------------------------------ | ------------------------------------------------------------ |
| **id**             | varchar(64)         | 主键 (Primary Key)                   | 会话的全局唯一 ID（建议用 UUID 或 NanoID），对应 `chat_history` 的 `session_id` |
| **title**          | varchar(100)        | 非空 (Not Null)                      | 对话标题（例如：“关于 Go 并发死锁的讨论”，可以由大模型在第一轮对话后自动生成） |
| **user_id**        | uint / int          | 普通索引 (Index)                     | 关联用户（如果你后续打算把单机版扩展成多用户系统，这个字段必不可少；目前单人使用可预留） |
| **created_at**     | datetime            | 普通索引 (Index)                     | 会话创建时间（用于侧边栏按时间倒序排列）                     |
| **updated_at**     | datetime            | 普通索引 (Index)                     | 最后活跃时间（每次该会话有新消息，更新此时间，让活跃会话置顶） |
| **deleted_at**     | datetime            | 普通索引 (Index)                     | GORM 软删除（用户删掉某个对话框时使用）                      |

```
import (
	"time"

type ChatSession struct {
	ID        string         `gorm:"type:varchar(64);primarykey;comment:'会话唯一标识(UUID/NanoID)'"`
	Title     string         `gorm:"type:varchar(100);not null;default:'新对话';comment:'会话标题(可由LLM生成)'"`

	UpdatedAt time.Time      `gorm:"index;comment:'最后活跃时间，用于列表排序'"`
	DeletedAt gorm.DeletedAt `gorm:"index"`
}
```
