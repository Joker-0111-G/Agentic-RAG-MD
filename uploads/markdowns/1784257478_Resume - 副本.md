## <img src="assets/project-diagram-solid.svg" width="50px"> 项目经历

- [<strong>IM-System 即时通讯系统</strong>](https://github.com/Joker-0111-G/IM-System)                                                  2025.08-2025.09                

  __项目描述：__基于 Go 并发特性构建的 C/S 架构轻量级控制台多用户聊天系统。项目旨在实践高并发网络编程，实现了非阻塞的实时消息处理、安全的状态同步与高效的资源调度。

  __核心职责与实现__

   * **并发架构与状态安全：**设计“一连接一协程”模型，利用全局 Channel 作为消息总线实现异步广播；引入 sync.RWMutex 保护全局在线用户 Map，保障高并发下的内存读写安全。
   * **多模式路由与全栈实现：**基于 net 库从零搭建 TCP 服务端与交互式 CLI 客户端。自主封装业务路由，支持全网群聊广播、P2P定向私聊( to|user|msg )、改名( rename )及状态查询( who )。
   * **连接生命周期管理：**结合 select  I/O 多路复用与 time.After 定时器，底层构建心跳检测与超时剔除机制，精准回收无响应的僵尸 Socket 连接，有效防止服务端协程泄漏。

  __技术栈：__Go, TCP Socket, Goroutine, Channel, RWMutex

- [<strong>Agentic RAG 个人 Markdown 智能知识库</strong> ](https://github.com/Joker-0111-G/Agentic-RAG-MD)                      2026.02 - 2026.04

  __项目描述：__独立设计开发的代理式检索增强生成（Agentic RAG）后端服务。项目旨在突破传统 RAG 单向检索的限制，支持解析本地 Markdown 笔记并提供具备复杂意图识别的流式对话问答能力。

  __核心职责与实现__

   * **Agentic 架构与意图路由：**引入大模型 Function Calling 技术落地 ReAct 核心工作流。自主封装 Go 原生工具函数，使智能体能动态调度 MySQL 元数据查询与本地磁盘 I/O，显著提升跨文档与时间维度查询的准确率。
   * **多轮上下文管理与存储优化：**结合 MySQL 与 Redis 打造二级缓存机制处理对话记忆。利用 Redis Pipeline 批量操作与 LTRIM 指令实现上下文“滑动窗口”，精确在内存中保留最近 10 条高频对话；并设计 Cache Miss 数据库兜底策略，在保障对话连贯性的同时严格控制大模型 Token 消耗。
   * **流式交互与服务高可用：**基于 Gin 框架构建 RESTful API，底层引入 Server-Sent Events (SSE) 协议并结合 Go Channel，实现 Agent 思考状态与文本的无阻塞“打字机”式实时推送。利用 Redis INCR 命令构建经典固定窗口限流器 (Rate Limiter)，有效拦截恶意请求并保护 API 额度安全。

  __技术栈：__Go, Gin, GORM, MySQL, Redis, LLM Function Calling, SSE
